# CERCEG - Centro de Recuperação de Cães e Gatos

## Descrição do projeto
O CERCEG é uma aplicação web desenvolvida para a disciplina de Programação Web Front-end com o objetivo de divulgar um centro de recuperação de cães e gatos, incentivando a castração responsável, o cuidado animal e a conscientização da comunidade.

A proposta do projeto está alinhada aos Objetivos de Desenvolvimento Sustentável (ODS), promovendo bem-estar animal e impacto social positivo na comunidade local.

---

## Funcionalidades
- Página principal institucional
- Navegação entre seções por menu âncora
- Seção "Quem somos"
- Seção "Como funciona"
- Cards informativos
- Rodapé com links úteis
- Layout responsivo para desktop
